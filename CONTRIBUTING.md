# Contributing to NotionExporter

Thank you for considering contributing to **NotionExporter**!

## 🔧 Guidelines (Quick Version)

- Keep changes focused and minimal
- Follow .NET code conventions
- Include unit tests when possible
- Don't reformat unrelated code
- Submit PRs against `main` branch
- Respond to feedback if maintainers comment

---

## 🚦 Before You Start

By contributing, you confirm that:

- Your contribution is original
- You have rights to contribute the code
- You agree to license it under the MIT license

---

## 🧱 Code & Style

- Follow [Microsoft's .NET Design Guidelines](https://learn.microsoft.com/en-us/dotnet/standard/design-guidelines/)
- No unnecessary whitespace or reformatting
- All code must compile with no errors/warnings

---

## 🧪 Tests

- Run all existing tests before submitting
- Add tests for new functionality where applicable

---

## 🛠️ How to Contribute

1. Fork this repository
2. Create a feature branch (e.g. `feature/export-pages`)
3. Make your changes (focused, tested, and clean)
4. Submit a pull request with a clear description
5. Respond to feedback if requested

---

## 💬 Questions / Issues

- Use GitHub Issues to report bugs or suggest features
- Use PRs to contribute code
