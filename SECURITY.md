# Security Policy

## 📢 Reporting a Vulnerability

If you discover a security vulnerability in **NotionExporter**, we strongly encourage you to report it responsibly.

Please **do not open a public GitHub issue** for security-related concerns.

Instead, contact the maintainer privately at:

📧 **[172640+patriksima@users.noreply.github.com]**

We will review your report promptly and work to address the issue as quickly as possible. Responsible disclosure is appreciated.

---

## ✅ Supported Versions

| Version         | Supported |
|------------------|-----------|
| `main` branch     | ✅ Yes     |
| Previous versions | ❌ No      |

If you're using an older version, please upgrade to the latest release.

---

## 🔒 Disclosure Policy

Once a vulnerability is confirmed:

1. A fix will be developed in a private branch
2. A coordinated release will be made including:
   - A patched version
   - A security advisory (if applicable)
   - Attribution to the reporter (if desired)
